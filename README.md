Site institucional — Dra. Mabele Sanches

Site institucional premium para a Dra. Mabele Sanches, desenvolvido para apresentar tratamentos odontológicos e estética facial com uma experiência visual elegante, acolhedora e responsiva.

O projeto utiliza HTML, CSS e JavaScript puro — sem frameworks ou dependências JavaScript externas.

## Recursos

- Header fixo com navegação responsiva e menu mobile.
- Hero com chamada principal, logo e CTA de agendamento.
- Seções de apresentação, especialidades, diferenciais, galeria, depoimentos, antes e depois, contato e localização.
- Galeria com visualização ampliada das fotos (lightbox).
- Comparador interativo de imagens de antes e depois.
- Slider automático de depoimentos.
- Botão flutuante do WhatsApp e botão de voltar ao topo.
- Mapa incorporado do Google Maps.
- Banner de cookies preparado para LGPD.
- SEO básico: meta tags, Open Graph, Twitter Card, Schema.org, `robots.txt` e `sitemap.xml`.
- Arquivos de exemplo para cabeçalhos de segurança em Nginx, Apache, Netlify e Vercel.

## Estrutura de arquivos

```text
dra-mabele-sanches/
├── assets/
│   ├── icons/
│   │   └── favicon.svg
│   └── images/             # Logo, fotos da clínica e imagens antes/depois
├── security/               # Configurações e documentação de segurança
├── index.html              # Página principal
├── style.css               # Estilos e responsividade
├── script.js               # Interações do site
├── privacidade.html        # Política de privacidade
├── termos.html             # Termos de uso
├── robots.txt
└── sitemap.xml
```

## Como abrir o site

Abra o arquivo `index.html` em seu navegador. Para uma visualização mais próxima do ambiente de produção, publique os arquivos em uma hospedagem estática com HTTPS.
